Frequently Asked Questions

How does PDFSplit ensure complete document privacy?

PDFSplit executes entirely in your browser using client-side JavaScript and ISO 32000-1 PDF structure manipulation via pdf-lib. Your documents stay in local memory and are never uploaded to any remote server.

Is there an artificial file size or page count limit?

There are no artificial file size caps or server queues. You can split, merge, reorder, and rotate PDFs up to the available memory of your browser.

Can I split into individual single-page PDFs or extract ranges like 1-3, 5?

Yes. Enter standard ranges such as 1-3, 5, 8-10 or leave the range blank for all pages, then choose whether to combine extracted pages into one PDF or download separate single-page PDFs.

Does PDFSplit reorder or rotate pages as well as merge files?

Yes. Switch to Merge Multiple PDFs to change file order before combining, or use Reorder & Rotate Pages to move, rotate 90 degrees clockwise, or delete individual pages before exporting.
